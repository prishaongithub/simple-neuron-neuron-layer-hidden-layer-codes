# Neural Networks From Scratch 🧠

*A step-by-step implementation of neural networks using NumPy*

## 📌 Overview

This repository documents my journey of **building neural networks completely from scratch**, without using deep learning frameworks.
The goal is to deeply understand the **mathematical and computational foundations** behind neural networks by implementing every component manually using **NumPy**.

Each concept is implemented in a **separate Jupyter Notebook**, making the learning modular, traceable, and easy to revise.

This repository focuses on **how neural networks work internally**, not just how to use them.

---

## 🧩 What’s Covered

The notebooks in this repository progressively build up a neural network from the ground up, covering:

* Neurons and basic computation
* Neural network layers
* Forward propagation
* Activation functions
* Loss functions
* Cross-Entropy Loss
* Backpropagation (from scratch)
* Optimisation techniques (Gradient Descent, parameter updates)

Each notebook focuses on **one concept only**, keeping things simple and conceptually clear.
